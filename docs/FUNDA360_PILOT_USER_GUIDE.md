Funda360 currently provides role-aware workflows across academics, learners, guardians, attendance, timetable, assessments/report cards, homework, finance, HR/leave, admissions, communications, behaviour/safeguarding and portals.

The visible navigation differs by role and tenant permissions. Not every user sees every module.
