## How the data model holds this

The assessment tables (`learning_assessments`, `assessment_questions`, `assessment_question_keys`) already carry marks per question, a duration, and an assessment-level description. The pack's Funda360 revision check (`A_FA`) uses 1 or 2 marks per question as a *practice* convention and is titled "Funda360 practice, not the DBE assignment". Do **not** reuse those marks as the DBE marks.

Content Studio has no manual editor for the details above: they are entered as new draft assessment units (platform administrators, then the normal review, validation and approval path). Until someone does that, FA.01 stays an objective with no official task behind it, and the interface must not describe any Funda360 check as the formal assessment.
